# QuotaCraft v0.1.0

首个可运行 MVP：按任务重要性、截止时间和收尾预算安排 Codex 额度，并将验收成果留在本地记录中。

- 本地 Web 控制台、CLI、7 个 stdio MCP 工具与 SQLite 持久化。
- 官方 app-server 额度读取，多个窗口、缺失数据、套餐切换与周期变化处理。
- 显式开启的串行 Codex 执行器、预留线保护、运行时间上限和断点恢复。
- 人工验收门槛、按时完成记录、账号观测成本和估计误差。
- 手动信号、可选官方 X API、单独展示的社区预测与实验历史模型。
- 额度恢复、公告、预留线、暂停和待验收消息；页面打开时可接收浏览器通知。
- 独立且明确标记的演示空间，桌面/375px 适配，键盘弹窗与减少动态效果支持。

这是预发布版本。实验预测尚未校准；成本由用户估计；MCP 依赖宿主遵守准入；其他设备仍可消耗同一额度。本版没有移动推送、自动购买或兑换重置、跨账号调度和无损旧会话续接。
